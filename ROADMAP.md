# ZCalendar Roadmap 🗓️

This document describes the planned direction of **ZCalendar**.

ZCalendar is being developed as a simple, native-feeling **Jalali/Persian calendar for Linux**, with a focus on Persian-speaking users.

The roadmap is not a fixed contract. Priorities may change based on user feedback, technical limitations, and community contributions.

---

## 🟢 Phase 1 — Foundation

> Build a functional and clean calendar application.

* [x] Basic Jalali calendar
* [x] Persian user interface
* [x] Display current month
* [x] Highlight today's date
* [x] Navigate to previous month
* [x] Navigate to next month
* [x] Persian weekday names
* [x] Persian font support
* [x] Initial GTK4 interface
* [x] Rust-based implementation

---

## 📌 Current Focus

The immediate goal is **not** to implement everything on this list.

The current priorities are:

1. Make the core calendar experience solid.
2. Improve interaction with individual days.
3. Add Iranian holidays and important occasions.
4. Keep the codebase simple and maintainable.
5. Make it easy for contributors to participate.
